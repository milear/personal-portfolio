Quick notes

Deploying on Netlify (recommended)
1. Go to https://app.netlify.com/sites -> "New site from Git"
2. Connect your GitHub account and authorize Netlify to access your repositories.
3. Select the repository: milear/personal-portfolio
4. Set Build command: (leave empty)
5. Set Publish directory: `.` (root) or leave empty for static root
6. Click "Deploy site". After the build completes your site will be live.
